# فرع `android` — نسخة تطبيق الأندرويد

هذا الفرع مخصص لجعل الأداة **تطبيق أندرويد فعليًا** بدل الاعتماد على WebView خام،
مع الحفاظ على إمكانية الاستمرار في التطوير عبر Google AI Studio دون تعارضات.

## القاعدة الذهبية

| الفرع   | الدور |
|--------|-------|
| `main`    | **مخرجات AI Studio فقط.** أي تعديل تطلبه من AI Studio يُدفع هنا. لا تعديلات يدوية native هنا. |
| `android` | **التخصيصات الخاصة بالأندرويد** فوق `main`: مجلد `android/` الملتزم به، تعديلات `capacitor.config.ts`، أي كود native إضافي. |

AI Studio يعيد توليد الملفات كاملة ولا يدمج تعديلاتك اليدوية — لذلك لا تدفع
مخرجات AI Studio إلى هذا الفرع أبدًا، ولا تطلب من AI Studio التعديل عليه.

## المزامنة: سحب تحديثات AI Studio إلى فرع android

```bash
git checkout android
git merge main        # حل أي تعارض لصالح نسختك عند الحاجة
npx cap sync android  # نسخ أحدث بناء ويب إلى المنصة
```

بعد الدمج، راجع التغييرات في `android/` قبل البناء، لأن `main` قد يكون غيّر
`capacitor.config.ts` أو أصول الواجهة.

## ملاحظات تقنية

- مجلد `android/` **ملتزم به** في هذا الفرع (أُخرج من `.gitignore`) — أي تخصيص
  native (مثل `AndroidManifest.xml`، الأيقونات، ألوان شريط الحالة) يبقى محفوظًا.
- **الملفات الثنائية مخزنة كنص base64** (ملفات `*.b64`: أيقونات اللانشر، شاشات
  البداية، و`gradle-wrapper.jar`) لأن قناة الدفع المستخدمة لهذا الفرع لا تنقل
  ملفات binary. وهي محفوظة تحت `android/binary-assets/` (بنفس البنية الداخلية
  لمجلد `android/`) — **وليس** داخل `app/src/main/res/` لأن دمج موارد أندرويد
  يرفض أي ملف هناك لا ينتهي بـ `.xml` أو `.png`. بعد أي clone نفّذ:
  `python3 scripts/restore-android-binaries.py`
  (الـ CI يفعل ذلك تلقائيًا قبل البناء).
- لا تشغّل `npx cap add android` فوق هذا الفرع — المنصة موجودة أصلًا.
  استخدم `npx cap sync android` فقط.
- مخرجات البناء (`android/app/build/`) ما زالت مُتجاهلة.
- الـ workflow في هذا الفرع يعمل بـ `npx cap sync android` بدل `cap add`،
  ويُشغَّل تلقائيًا عند الدفع إلى فرع `android`.
- قيد معروف: مزودا الترجمة المدمجان (Gemini / Yandex) يعملان عبر خادم Express
  (`/api/*`) وهو غير موجود داخل الـ APK — من مهام هذا الفرع نقل هذا المنطق
  للعميل أو معالجته بطريقة مناسبة للأندرويد.
